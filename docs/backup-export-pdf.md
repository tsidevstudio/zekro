# Zekro Backup, Export and PDF

Zekro can provide backup, export and PDF-related workflows for supported records.

## Good practices

- Keep backups in trusted locations.
- Review exported data before sharing it.
- Treat debt records and generated PDFs as potentially sensitive financial information.
- Keep original copies until imports or restores are confirmed.

## Publication boundary

This repository does not publish internal database structures, private storage formats or implementation details.
